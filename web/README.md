# Behavior Review evidence viewer

Static Vite + React + TypeScript viewer for the review report. The current report at `public/data/report.json` is a clearly labeled fixture (`fixture: true`) and should be replaced with engine-generated evidence before demo use.

## Local commands

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm run preview
```

## Vercel

- Root Directory: `web`
- Build Command: `npm run build`
- Output Directory: `dist`
